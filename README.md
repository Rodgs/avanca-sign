# Avança Sign

Programa para assinar vários PDFs de uma vez, com certificado digital ICP-Brasil do tipo A3, no token, no cartão ou na nuvem. Distribuído pela Secretaria Municipal de Finanças de Belém aos órgãos e entidades da Prefeitura de Belém, como parte do Programa Avança SEFIN.

## Onde baixar

Baixe sempre pela página oficial **https://avancasefin.com.br/avanca-sign**, que mostra a versão em uso, a impressão digital SHA-256 de cada instalador e o passo a passo de instalação no Windows e no Mac.

Os instaladores ficam nas [versões publicadas](https://github.com/Rodgs/avanca-sign/releases) deste repositório. Confira a impressão digital SHA-256 do arquivo baixado antes de abrir. Arquivo obtido por outro caminho não deve ser usado.

## O que faz

- Assina em lote os PDFs escolhidos ou os de uma pasta, numa única operação.
- Carimbo configurável, com prévia antes de assinar, e assinatura que nunca fica por cima de outra assinatura, carimbo ou texto.
- Os assinados ficam ao lado dos originais ou na subpasta Assinados, e o original nunca é alterado.
- Confere as assinaturas de PDFs já assinados.
- A assinatura é feita no próprio computador. Os documentos e o PIN não passam por nenhum servidor.

## Conteúdo deste repositório

Este repositório guarda só os instaladores oficiais e as notas de cada versão. O código-fonte não é publicado.
